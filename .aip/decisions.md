# Decision Log

プロジェクトの重要な意思決定を記録します。

## Format

```
### [日付] 決定事項
- **背景**: なぜこの決定が必要だったか
- **選択肢**: 検討した選択肢
- **決定**: 選んだ選択肢
- **理由**: なぜその選択肢を選んだか
```

### 2026-05-03 トピック・インデックス追記スクリプトを既存notion_clientと別実装にした
- **背景**: 既存ページ末尾へ md を追記したいが、`src/integrations/notion_client.py` の `_markdown_to_notion_blocks` は Transcript セクションをトグル化する暗黙ロジックや「Summary/Timestamps/Takeaways」セクション判定が組み込まれており、汎用な末尾追記用途には向かない。`####` 見出しや `*italic*` のインライン書式、divider、quote にも非対応
- **選択肢**:
  1. 既存 `notion_client.py` を拡張して #### / quote / divider / italic を追加対応
  2. 既存ロジックは触らず、シンプルな汎用スクリプト `append_index_to_notion.py` を別途作成
- **決定**: 選択肢2
- **理由**: 既存 `notion_client.py` は本番処理パスで使用中で副作用が大きい。今回は「インデックス追記」という単発・読み取り中心のユースケースなので、独立したシンプルな変換器を持つ方が安全かつ再利用しやすい

### 2026-05-03 リサーチで判明した本編の表記ゆれをインデックス側で訂正注記した
- **背景**: Whisper の聞き取りで「山際順次」「野木下図書館」「神奈川厚生の高橋先生」などの表記が出ていたが、リサーチで一部誤りが判明
- **選択肢**:
  1. 元のトランスクリプトを書き換える
  2. 元のトランスクリプトはそのまま保持し、追記したインデックス側で「※本編は◯◯と聞こえているが正名は△△」と注記
- **決定**: 選択肢2
- **理由**: 元の Whisper 出力は監査可能な原資料として保存しておきたい。訂正は読者に向けたコンテキスト上で示すのが分かりやすく、後から本編を再聴取するときも比較しやすい
